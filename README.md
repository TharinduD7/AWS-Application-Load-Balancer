# AWS-Application-Load-Balancer
Distribute incoming application traffic across multiple EC2 web servers using an AWS Application Load Balancer (ALB).
In this project, I explored how to distribute incoming application traffic across multiple EC2 web servers using an AWS Application Load Balancer (ALB).


Through this project, I gained practical experience with:
🔹 Amazon EC2
🔹 Application Load Balancer (ALB)
🔹 Target Groups and Health Checks
🔹 AWS VPC and Security Groups
🔹 High Availability and Traffic Distribution
